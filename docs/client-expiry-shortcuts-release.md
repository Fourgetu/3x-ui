# 客户端有效期快捷延长发布记录

日期：2026-10-23（Asia/Shanghai）。候选版本：`v3.10.2-fourgetu.5`。

## 功能与兼容

- 在客户端编辑窗口的过期时间下方加入 `+1个月`、`+3个月`、`+半年`、`+一年`，小屏幕自动换行。
- 未到期时从当前表单中的到期时间顺延；已过期或未设置时从点击时的当前时间计算。连续点击累加，点击保存后才提交；取消不会修改服务器数据。
- 按自然月计算，保留本地时分秒并处理月底和闰年。例如 2027-01-31 加一个月得到 2027-02-28；2028-02-29 加一年得到 2029-02-28。
- 首次使用后开始模式仍使用原来的天数输入，不显示绝对日期快捷按钮。
- 补齐全部 13 种语言的按钮文案。现有用户限速、模板、中转、节点命名、多客户端二维码等定制功能保持原实现。
- 不增加 API，不改数据库结构；继续使用已有客户端保存接口。

## 发布中发现并修复的问题

- 首个 `.2` 候选使用 Go 1.27.2，云端 govulncheck 检测到 `GO-2026-6809`（crypto/x509）。将最低工具链版本提升为 Go 1.27.3。
- `.3` 候选完整前端测试发现其他语言缺失翻译键，现已全部补齐。
- 原内置 Xray v26.10.10 已被官方撤下，安装包下载返回 404。官方 v26.10.21 发布说明解释了证书问题和替代版本，因此将 Linux、Windows 及 Docker 的内核下载统一固定为 v26.10.21。面板上游基线仍为 v3.10.2，没有进行其他上游版本合并。
- `.4` 候选完整通过 1,906 项测试及八平台产物检查，但 npm audit 报告 DOMPurify 3.4.16 严重漏洞。仅将该依赖及 override 下限更新到 3.4.17，本地生产依赖审计已为 0 vulnerabilities。
- `.2`、`.3`、`.4` 标签不移动，保留为明确标注不可安装的预发布记录，没有提升稳定版。最终候选使用 `.5`。
- 发布验证流程增加 Linux amd64 Xray 启动检查，并保留面板/GOST 启动、包内容、八平台和校验和检查。
